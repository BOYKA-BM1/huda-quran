# هُدى القرآن

تطبيق إسلامي عربي (RTL): مصحف وتلاوة، مواقيت صلاة وأذان، أذكار، قبلة، ختمة وحفظ، حاسبة زكاة، تقويم هجري، ومساعد ذكاء اصطناعي.
يعمل كموقع (PWA) ويتحوّل لتطبيق أندرويد/آيفون عبر **Capacitor** من نفس الكود.

## الهيكل

```
www/                  ← التطبيق كله (HTML/CSS/JS خام، بدون بناء)
  index.html          ← الواجهة (كل الصفحات)
  css/                ← app.css (التصميم الحالي) · native.css · features.css · fonts.css (يولّده السكربت)
  js/                 ← app.01…05.js (الكود الأصلي مقسّم) + ui-handlers · features-* · quran-data · native · pwa
  sw.js               ← Service Worker الوحيد (كاش مسبق للعمل أوفلاين)
  data/               ← يولّده `npm run data` (القرآن، التفسير، الترجمة…)
backend/              ← Express: الذكاء الاصطناعي (Groq) + بيانات إسلامية. المفتاح يعيش هنا فقط
scripts/              ← fetch-data.js (تنزيل+تحقق) · patch-android.js · serve.js
tests/ + backend/test ← اختبارات
.github/workflows/    ← بناء APK مجاناً على GitHub
```

## التشغيل المحلي

```bash
npm run serve                      # الواجهة على http://localhost:8080
cd backend && cp .env.example .env # ضع GROQ_API_KEY ثم:
npm install && npm start           # الباك إند على :3000
```
عدّل `www/js/config.js` ليشير `backendUrl` إلى رابط الباك إند (محلي أو منشور).

## ⚠ قبل أي شيء: المفتاح القديم
المفتاح الذي كان داخل `index.html` أصبح علنياً. **ألغِه (Revoke) من console.groq.com** وأنشئ مفتاحاً جديداً يوضع على السيرفر فقط (`GROQ_API_KEY`). أُزيل من الكود، لكنه يبقى في تاريخ git إن كان المشروع مرفوعاً.

## تنزيل البيانات (مرة واحدة، يحتاج إنترنت)

```bash
npm run data        # القرآن (عثماني) + التفسير الميسّر + ترجمة + خطوط محلية + قائمة قراء آية بآية
npm run data:all    # + تفاسير إضافية (ابن كثير، السعدي…) + البخاري/مسلم/الأربعون النووية
npm run data:check  # يتأكد بدون إنترنت أن الملفات لم تُعدَّل (بصمة SHA-256)
npm run validate:data   # نفس data:check
npm run validate:release # بوابة ما قبل الإصدار (بيانات + SW + ملفات أساسية)
npm run check:all        # validate:data + test + validate:release
```

### إنتاج (Backend)
- `NODE_ENV=production` يتطلب `FRONTEND_URL` قائمة أصول صريحة (ممنوع `*`).
- `GROQ_API_KEY` على السيرفر فقط — لا تضعه في `www/`.

السكربت **يرفض** أي بيانات ناقصة: يتحقق من ١١٤ سورة و٦٢٣٦ آية وعدد آيات كل سورة، ويقارن نسختين من النص، ويكتب بصمة للنص. بعد التنزيل يعمل المصحف والتفسير والبحث بدون إنترنت.
> المصادر مفتوحة لكن **ليست تصديقاً شرعياً**: قارن عيّنة مع مصحف المدينة، وراجع درجات الأحاديث والتفاسير مع متخصص قبل النشر.

## تحويله لتطبيق أندرويد بدون Android Studio

1. ارفع المشروع إلى GitHub.
2. تبويب **Actions ← Build Android APK ← Run workflow**.
3. بعد دقائق نزّل `huda-quran-debug-apk` وثبّته على موبايلك.

(أو محلياً: `npm install && npm run data && npm run android:add && npm run android:open` — يحتاج Android Studio.)
للنشر على Google Play تحتاج توقيعاً (keystore) وبناء release — لم يُجهَّز هنا.

## التصميم الجديد (v5)
- **مظهران فقط:** ورقي (الافتراضي) وزمردي، بزر واحد (◐).
- **وضوح الورقي:** `css/paper.css` يُولَّد تلقائياً بـ `python3 scripts/gen-paper.py` من تحليل ألوان الكود القديم (خلفيات خضراء داكنة ← أسطح ورقية، ذهبي فاتح ← ذهبي غامق…). أعد تشغيله بعد أي تعديل ألوان في `app.css`. نتيجة فحص التباين الآلي: من ٥٤٠ نصاً ضعيف التباين إلى ٤ (كلها نتائج كاذبة من الفحص).
- **الرئيسية:** كارت الصلاة الداكن ← الصلوات الخمس ← تابع القراءة ← **هدف القراءة اليومي** ← **آية اليوم** ← كروت الخدمات.
- **قارئ المصحف** (`js/reader.js`): تمرير متواصل أو صفحات ٦٠٤، **ترجمة تحت الآية**، **وضع الحفظ** (يخفي النص حتى تضغط)، تمرير تلقائي، استماع يتتبّع الآية، تفسير، مفضلة، ملاحظات، بحث نصي وصوتي، فهرس، علامات.
- **المسبحة** (`js/tasbeeh.js`): صفحة جديدة بالكامل (كانت فارغة ومحوّلة لحصن المسلم): عدّاد كبير بحلقة تقدّم، أهداف ٣٣/٩٩/١٠٠، ٨ أذكار مقترحة بعدّاد لكل ذكر، اهتزاز، إحصاءات (اليوم/الإجمالي/أيام متتالية).
- **إصلاحات:** كلمة `u0022` الضخمة في «ورد اليوم»، سحب الخلفية الرمادية، التمرير بالماوس (انظر الأسفل).
- **التمرير:** أُزيل `scroll-behavior:smooth` و`overscroll-behavior` وحاويات التمرير المتداخلة، وزر Space لم يعد يُشغّل الصوت.

## v8 — المشغّل والصوت
- **مشغّل التلاوة العائم** (`js/dock.js`, `css/dock.css`): كبسولة بنصف دائرة على الطرفين. خاملة: زر «استماع» ذهبي كبير + شارة القارئ + ⋯. نشطة: سابق/تشغيل-إيقاف/تالي + السورة والآية والقارئ + قائمة (السرعة، تكرار الآية، تمرير تلقائي، علامة مرجعية، مشاركة، تغيير القارئ، إيقاف).
- **تشغيل متواصل طبيعي**: يحمّل الآية التالية مسبقاً فلا وقفة بين الآيات، ويكمل للسورة التالية تلقائياً، مع إعادة محاولة قبل الرجوع لملف السورة. يبدأ من أول آية ظاهرة أمامك.
- **اختيار القارئ** من المشغّل: كل القرّاء (الأشهر أولاً) + بحث، وبجانب كل قارئ زر تحميل: حفظ للاستماع **بدون إنترنت** (يُشغَّل من تخزين التطبيق) / حفظ ملف MP3 / جزء عمّ كاملاً، مع نسبة تقدّم وعرض المساحة المستخدمة.
- **إصلاح خطأ ربط القرّاء** (`js/audio.js`): الدوسري كان يشغّل صوت المطرود والشريم صوت الشاطري. صُحّحت ونُظّفت بقائمة `audio-editions.json` عند توفرها.
- نقطة الاتصال أصغر (٥px). أُزيل `scroll-behavior:smooth` الذي أعادته `upgrade.css` (يعطّل عجلة الماوس).

## ما تم في هذه النسخة
- **أمان:** إزالة مفتاح Groq، وتمرير الذكاء الاصطناعي عبر السيرفر (`/ai/chat/stream` بث SSE)، إزالة مفتاح المستخدم، `trust proxy`، حد أشد لطلبات الـ AI، تعقيم نصوص المجتمع/البحث (XSS)، حذف نظام الحسابات الميت الذي كان يخزّن كلمات مرور على الجهاز، تعطيل الإعلانات.
- **بنية:** تقسيم الملف الضخم، حذف النسخة المكررة (`frontend/`)، service worker واحد بكاش مسبق (يعمل أوفلاين)، manifest واحد، برومبت AI موحّد، حذف النموذج الموقوف.
- **إصلاح ٣٧ دالة** كانت مستدعاة من الأزرار وغير معرّفة أصلاً (المفضلة، الملاحظات، مؤقت النوم، المشغّل المصغّر، إعدادات القراءة، الإعدادات، التفسير، الختمة…).
- **ميزات جديدة:** حاسبة الزكاة، أوقات الإشراق/الضحى/منتصف الليل/ثلث الليل الأخير، بانر وتذكير الجمعة، مناسبات إسلامية قادمة بعدد الأيام + الأيام البيض، تذكير قبل الصلاة بـ١٥ دقيقة، تصحيح اليوم الهجري ±٢، تلاوة آية بآية مع تكرار الآية، تفسير الآية من قائمة الآية.
- **تطبيق:** إعداد Capacitor، إشعارات صلاة أصلية (تعمل والتطبيق مغلق)، زر الرجوع في أندرويد، أذونات أندرويد، workflow للبناء.

## ما لم يُنفَّذ / يحتاج منك (بصدق)
| البند | الوضع |
|---|---|
| تنزيل القرآن/التفسير/الحديث/الخطوط | **يتم بتشغيل `npm run data`** — لم أستطع التنزيل من بيئتي (لا إنترنت) فاختبرت السكربت على خادم وهمي |
| تحقق من أسماء قراء آية بآية | القائمة في `ui-handlers.js` من معرفتي، ويصفّيها السكربت بقائمة المصدر؛ أي قارئ غير متاح يرجع تلقائياً لتشغيل السورة كاملة |
| تحميل ملفات صوت كل القرآن لقارئ واحد دفعة واحدة | غير مُجهَّز عمداً (حجمه بالجيجابايت): التحميل لسورة أو لجزء عمّ |
| الصوت في الخلفية (والشاشة مقفولة) | **غير منفَّذ** — يحتاج Plugin/Foreground Service ويُختبر على جهاز حقيقي |
| صوت أذان مخصّص في الإشعار | غير منفَّذ (يحتاج ملفات صوت في موارد أندرويد) |
| آيفون | غير مجهَّز (يحتاج Mac أو خدمة بناء مثل Codemagic + حساب Apple) |
| الحسابات والمجتمع والنقاط | ما زالت **محلية على الجهاز** (ليست مشتركة بين المستخدمين) حتى يُبنى لها سيرفر وقاعدة بيانات |
| مراجعة المحتوى الفقهي | لازمة من متخصص قبل النشر (الزكاة، الفقه الميسّر، الأذكار، الأحاديث…) |
| صفحات القبلة والأذكار/الورد والحصن والصلاة والتقويم والمجتمع… | ما زالت بتصميمها القديم (لكن مقروءة في المظهرين) — لم تُعَد بنفس لغة الرئيسية والمسبحة والمصحف بعد |
| تلوين التجويد · معاني الكلمات · تصحيح التلاوة بالذكاء الاصطناعي | غير منفَّذة: تحتاج بيانات/خدمة (انظر تقرير المقارنة مع التطبيقات الأخرى) |
| نصوص أصغر من ١١px في بعض الصفحات القديمة (الأنبياء، الأحاديث، المصحف القديم) | موجودة في ٧ صفحات وتحتاج مراجعة يدوية |
| تقسيم الصفحة بالسطر (١٥ سطراً كالمصحف المطبوع) | غير منفَّذ: الآيات تتدفق داخل الصفحة بحسب بيانات الصفحة وتتصغّر لتناسب الإطار. التقسيم المطابق يحتاج خط مصحف المدينة وبيانات سطور |
| ألوان الورقي في الصفحات القديمة | طُبّق على المتغيرات الأساسية؛ بعض الصفحات الأقدم فيها ألوان ثابتة داخل HTML (مثل بطاقة دعاء اليوم) وتحتاج مراجعة بصرية على جهازك |
| رموز نهاية الآية ۝ | تظهر صحيحة بخط Amiri Quran (يُنزَّل محلياً بـ `npm run data`) |
| إصدارات Capacitor | مكتوبة `^7`؛ تأكد من أحدث إصدار متوافق عند أول `npm install` |
| اختبار على جهاز أندرويد حقيقي | لم يحدث — كل الاختبارات في متصفح headless |
